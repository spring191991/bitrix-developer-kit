# bitrix-developer-kit
Сборник профессиональных бэкенд-сервисов, утилит и кастомных компонентов на современном ядре 1С-Битрикс (D7, ООП, ORM).
### Набор бэкенд-сервисов и утилит для 1С-Битрикс (D7 / ООП)

Репозиторий представляет собой сборник готовых решений на ядре **1С-Битрикс D7** с применением **ООП**, автозагрузки **PSR-4** и интеграции по **REST API**. Полный текст и структуру конфигурации вы можете найти в исходном документе. 

### 📂 Основные модули

1. **Интеграция с REST API (ExchangeService.php)** — сервис для GET-запросов, валидации и обработки JSON.
2. **Мониторинг и логирование (Logger.php)** — отказоустойчивый инструмент перехвата исключений и записи в лог.

### ⚙️ Установка

Перенесите содержимое папки local/ в корень вашего сайта. Автозагрузка классов активируется автоматически через init.php.
