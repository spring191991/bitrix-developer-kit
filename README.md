# bitrix-developer-kit
Сборник профессиональных бэкенд-сервисов, утилит и кастомных компонентов на современном ядре 1С-Битрикс (D7, ООП, ORM).
### Набор бэкенд-сервисов и кастомных компонентов для 1С-Битрикс (D7 / ООП)

Репозиторий представляет собой модульный сборник готовых инженерных решений, архитектурных паттернов и утилит для платформы **1С-Битрикс**. Весь код написан строго на современном ядре **D7** с соблюдением принципов **ООП**, стандартов автозагрузки **PSR-4** и методологии **БЭМ** для фронтенд-части. 

Цель проекта — собрать переиспользуемую библиотеку инструментов, оптимизированных для высоконагруженных систем иEnterprise-разработки. 

### 📂 Структура репозитория
```
local/
 ├── components/                         # Кастомные компоненты Битрикс (D7 Class-based)
 │    └── spring/
 │          └── kpi.profile/            # [В РАЗРАБОТКЕ] Компонент Личного кабинета (ORM, Кэширование, БЭМ)
 │
 ├── php_interface/                      # Системная бэкенд-логика портала
 │    ├── init.php                      # Единая точка регистрации автозагрузки и событий ядра
 │    └── classes/
 │          └── Spring/
 │                └── Main/
 │                      ├── ExchangeService.php # Модуль интеграции с REST API (HttpClient, JSON-парсер)
 │                      └── Logger.php          # Модуль умного логирования и перехвата исключений
 └── logs/
       └── app_errors.log                # Защищенный лог критических сбоев платформы

```
### 🛠 Подробное описание модулей

### 1. Интеграция с REST API (ExchangeService.php)

Автоматизированный сервис для организации безопасного обмена данными с внешними информационными системами. 

* **Технологии:** \Bitrix\Main\Web\HttpClient, встроенные потоковые функции PHP, работа со сложными JSON-структурами.
* **Функционал:** Выполняет сетевые GET/POST запросы к сторонним API, валидирует ответы, декодирует JSON в ассоциативные массивы PHP и выполняет пакетную запись/обновление данных в СУБД (Инфоблоках).

### 2. Мониторинг и логирование исключений (Logger.php)

Отказоустойчивый инструмент для контроля стабильности работы сайта и сбора технических метрик. 

* **Технологии:** Событийная модель Битрикса (OnMainPageError), динамическая валидация типов (is_object, \Throwable).
* **Функционал:** Перехватывает критические сбои (включая SqlQueryException при падении БД), извлекает чистый текст ошибки и дописывает его в структурированном виде ([Дата/Время] Текст) в изолированный файл лога без перезаписи истории.

### 3. Личный кабинет сотрудника с KPI (kpi.profile) — *В процессе реализации*

Кастомный визуальный компонент нового поколения, построенный на PHP-классах (class.php). 

* **Технологии:** Наследование от \CBitrixComponent, выборка данных через Битрикс ORM (DataManager), статические хранилища памяти, многоуровневое кэширование, вёрстка шаблона по стандартам БЭМ.

### ⚙️ Установка и использование

Для внедрения утилит на проект перенесите содержимое папки local/ в корень вашего сайта 1С-Битрикс. Автозагрузка классов подтянется автоматически благодаря настроенному ядру в init.php.
