# bitrix-developer-kit
Сборник профессиональных бэкенд-сервисов, утилит и кастомных компонентов на современном ядре 1С-Битрикс (D7, ООП, ORM).
### Набор бэкенд-сервисов и кастомных компонентов для 1С-Битрикс (D7 / ООП)

Репозиторий представляет собой модульный сборник готовых инженерных решений, архитектурных паттернов и утилит для платформы **1С-Битрикс**. Весь код написан строго на современном ядре **D7** с соблюдением принципов **ООП**, стандартов автозагрузки **PSR-4** и методологии **БЭМ** для фронтенд-части. 

### 🛠 Описание модулей

### 1. Кастомный компонент карточки товара (product.info)

Компонент нового поколения на PHP-классах (class.php), предназначенный для оптимизированного вывода данных из торгового каталога. 

* **Технологии:** Наследование от \CBitrixComponent, выборка через Битрикс ORM (ElementTable, PriceTable), встроенное файловое кэширование, вёрстка по стандартам БЭМ.
* **Функционал:** 

  * Реализует проверку авторизации через современное ядро CurrentUser::get()->getId().
  * Выполняет безопасные, быстрые многотабличные ORM-запросы к таблицам элементов инфоблока и розничных цен модуля catalog.
  * Инкапсулирует тяжелые SQL-выборки в штатный кэш Битрикса (StartResultCache) с управляемым временем жизни (CACHE_TIME), полностью разгружая базу данных при повторных заходах.
  * Передаёт очищенные данные в изолированный HTML-шаблон, свёрстанный строго по методологии БЭМ (product-card, product-card__title, product-card__price).

### 2. Интеграция с REST API (ExchangeService.php)

Автоматизированный сервис для организации безопасного обмена данными с внешними информационными системами. 

* **Технологии:** \Bitrix\Main\Web\HttpClient, встроенные потоковые функции PHP, работа со сложными JSON-структурами.
* **Функционал:** Выполняет сетевые GET-запросы к сторонним API, валидирует ответы, декодирует JSON в ассоциативные массивы PHP и выполняет пакетную запись/обновление данных в СУБД (Инфоблоках) через объектную обёртку \CIBlockElement.

### 3. Мониторинг и логирование исключений (Logger.php)

Отказоустойчивый инструмент для контроля стабильности работы сайта и сбора технических метрик. 

* **Технологии:** Событийная модель Битрикса (OnMainPageError), динамическая валидация типов (is_object, \Throwable).
* **Функционал:** Перехватывает критические сбои (включая SqlQueryException при падении БД), извлекает чистый текст ошибки и дописывает его в структурированном виде ([Дата/Время] Текст) в изолированный файл лога без перезаписи истории.

### ⚙️ Установка и использование

Для внедрения утилит на проект перенесите содержимое папки local/ в корень вашего сайта 1С-Битрикс. Автозагрузка бэкенд-классов подтянется автоматически благодаря настроенному ядру в init.php. 

Вызов компонента на физической странице сайта: 
```php
$APPLICATION->IncludeComponent(
    "spring:product.info",
    "",
    array(
        "CACHE_TYPE" => "A",
        "CACHE_TIME" => "3600",
    )
);
```
