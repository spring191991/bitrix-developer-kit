# bitrix-developer-kit

Сборник бэкенд-сервисов, утилит и кастомных компонентов на современном ядре 1С-Битрикс (D7, ООП, ORM).

### Состав репозитория

Репозиторий представляет собой модульный сборник инженерных решений и архитектурных паттернов на ядре **1С-Битрикс** (D7, PSR-4, ООП, ORM).

---

### 🛠 Описание модулей

1. **Модуль асинхронного пакетного импорта каталога (spring.import)** — загрузка больших прайс-листов без длительного HTTP-запроса. Реализует очередь в СУБД, фоновый парсинг через Cron и пакетную обработку данных.
Пример корректного файла для тестирования импорта расположен в корне папки модуля: `local/modules/spring.import/test.xlsx`
2. **Кастомный компонент карточки товара (product.info)** — вывод данных с использованием ORM и файлового кэширования.
3. **Интеграция с REST API (ExchangeService.php)** — сервис для обмена данными с внешними системами через HTTP-клиент и JSON.
4. **Мониторинг и логирование (Logger.php)** — перехват сбоев и запись исключений в изолированный файл.

Полное описание исходного кода и инструкцию по установке вы найдете в репозитории.

---

### ⚙ Установка

Перенесите содержимое папки `local/` в корень вашего сайта 1С-Битрикс.
